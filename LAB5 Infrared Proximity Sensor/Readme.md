# LAB5 Infrared Proximity Sensor
![Infrared Proximity Sensor](https://abacasstorageaccnt.blob.core.windows.net/cirkit/7c39c73f-23f9-44c8-81a3-428e26415a55.png "Infrared Proximity Sensor")

> เซ็นเซอร์ตรวจจับวัตถุด้วยอินฟราเรดเป็นอุปกรณ์ที่ตรวจจับการมีอยู่ของวัตถุที่อยู่ใกล้เคียงโดยการปล่อยแสงอินฟราเรด (IR) และวัดสัญญาณสะท้อนกลับ มีการใช้งานอย่างแพร่หลายในแอปพลิเคชันที่ต้องการการตรวจจับวัตถุแบบไม่สัมผัส เซ็นเซอร์นี้มักพบในระบบอัตโนมัติ หุ่นยนต์ การตรวจจับสิ่งกีดขวาง และอินเทอร์เฟซแบบไร้สัมผัส
>
> ** การใช้งานทั่วไป:**
- การตรวจจับสิ่งกีดขวางในหุ่นยนต์
- ประตูอัตโนมัติและเจลล้างมือ
- หุ่นยนต์ติดตามเส้น
- ระบบไฟส่องสว่างตามระยะใกล้
- ระบบอัตโนมัติทางอุตสาหกรรมสำหรับการนับหรือคัดแยกวัตถุ

- 

**คำแนะนำการใช้งาน**
**วิธีการใช้งานเซ็นเซอร์ตรวจจับระยะใกล้แบบอินฟราเรดในวงจร**
1. จ่ายไฟให้เซ็นเซอร์ : ต่อVCCขาหนึ่งเข้ากับแหล่งจ่ายไฟ 3.3V หรือ 5V และGNDต่อขาอีกข้างหนึ่งเข้ากับกราวด์
2. เชื่อมต่อเอาต์พุต : ต่อOUTพินเข้ากับพินอินพุตของไมโครคอนโทรลเลอร์ (เช่น Arduino) หรือต่อโดยตรงกับ LED/ออดสำหรับงานง่ายๆ
3. ปรับความไว (ถ้ามี) : เซ็นเซอร์บางตัวมีโพเทนชิโอมิเตอร์สำหรับปรับช่วงการตรวจจับ หมุนโพเทนชิโอมิเตอร์ตามเข็มนาฬิกาหรือทวนเข็มนาฬิกาเพื่อปรับความไวให้เหมาะสม
4. อ่านค่าเอาต์พุต : เซ็นเซอร์จะส่งสัญญาณ HIGH เมื่อตรวจพบวัตถุในระยะทำการ และส่งสัญญาณ LOW ในกรณีอื่น ๆ สำหรับเซ็นเซอร์แบบอนาล็อก แรงดันไฟฟ้าขาออกจะแปรผันตามระยะห่างของวัตถุ


**ข้อควรพิจารณาที่สำคัญและแนวปฏิบัติที่ดีที่สุด**
- หลีกเลี่ยงการรบกวนจากแสงโดยรอบ : แสงโดยรอบที่แรง เช่น แสงแดด อาจรบกวนการทำงานของเซ็นเซอร์ได้ ควรใช้เซ็นเซอร์ในสภาพแสงที่ควบคุมได้ หรือป้องกันไม่ให้แสงส่องโดยตรง
- ตำแหน่งที่เหมาะสมที่สุด : ตรวจสอบให้แน่ใจว่าได้ติดตั้งเซ็นเซอร์ในมุมและระยะห่างที่เหมาะสมจากวัตถุเป้าหมายเพื่อการตรวจจับที่แม่นยำ
- ความเสถียรของแหล่งจ่ายไฟ : ใช้แหล่งจ่ายไฟที่เสถียรเพื่อหลีกเลี่ยงการทำงานที่ผิดปกติ
- ช่วงการทดสอบ : ทดสอบช่วงการทำงานของเซ็นเซอร์และปรับความไวให้เหมาะสมกับการใช้งานของคุณ
